# UI 文案中文化 (S-UI-copy-zh) — 2026-08-02

状态: ✅ 已合并 (PR #113, commit 32e905a)

## 背景
AUTO_ADVANCE 根任务循环 ⑤ UI 打磨连续推进:语义色(PR #111)之后,扫描
发现用户可见文案中英混杂——中文标题配英文空状态/按钮(「No backtest
results yet…」「No symbols on the watchlist.」「Compare selected runs」),
中文用户场景一致性缺口。

## 改动
- **空状态**: 「暂无回测结果…」「观察列表暂无标的。」
- **按钮**: 保存 / 刷新 / 对比所选回测 / 返回列表 / 详情
- **表头**(results/watchlist/index): 策略/代码/权益/收益/最大回撤/K 线/
  创建时间/更新时间/方向/数量/剩余现金/来源/状态
- **指标卡**: 期末权益 / 总收益率 / 最大回撤 / K 线数;h2/h3 回测详情/
  对比回测/权益曲线
- **app.js**: 错误提示(请选择策略)、compare hint(请选择恰好两条回测
  进行对比)、runs 状态(running→运行中)
- 测试: TestUICopyLocalized 契约(三页空状态 + results 关键文案 + JS
  文案)+ TestAppJSCompareView 的 compare-hint 断言同步为中文

## 验收
- `go test ./... -count=1` 全绿
- dev-up.sh 10/10 smoke(serve + PG + futu 网关)
- 逐端点文案契约 12/12
