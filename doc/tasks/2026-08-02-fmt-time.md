# 时间戳显示层本地化 (S-UI-fmt-time) — 2026-08-02

状态: ✅ 已合并 (PR #147, commit 2814580)

## 背景
AUTO_ADVANCE 根任务循环 ⑥ 老板长期目标(UI 打磨):表格时间列原样输出
ISO 字符串("2024-06-01T08:00:00+08:00"),富途/IB 面板惯例是本地时间
"YYYY-MM-DD HH:MM"。四处时间列统一接入显示层转换。

## 改动
1. **app.js**:
   - 新增 `fmtTime(iso)`:ISO → 本地 `YYYY-MM-DD HH:MM`(padStart 补零),
     空值/非法值原样兜底(NaN 校验后返回原串)。
   - 应用:订单表 `fmtTime(o.create_time)`、回测列表
     `fmtTime(item.created_at)`、交易记录 `fmtTime(t.ts)`、覆盖表
     `fmtTime(b.min_ts)/fmtTime(b.max_ts)`(原 `slice(0,16)` 的
     T 分隔符输出一并修正)。
   - 排序不受影响:sortItems 用原始字段值,仅显示层转换。
2. 测试: TestTimeFormattingJS(8 断言 + 2 反断言 slice 已删除)。

## 备注
- fmtTime 是纯显示层函数,与服务端时区(Asia/Shanghai 存储)解耦:
  浏览器本地时区渲染,跨时区看盘时时间跟着本地走。
- 后续若需要"相对时间"(x 分钟前),可在 fmtAge 基础上扩展,
  与表格默认排序(时间降序)语义一致。
