## 改动
1. `SIDE_ZH`/`STATUS_ZH` 映射 + `sideZh`/`statusZh` helper(app.js):
   未知值原样透传,不误译。
2. 接入三处动态渲染点:
   - renderOrders 订单方向列 → `sideZh(o.side)`(保留 side-buy/side-sell)
   - renderTradesTable 回测 trades 方向列 → `sideZh(t.action)` + 语义色

3. **顺带修复历史 bug**(2a15758 引入):`appendRow` 对预构建 td 元素走
   `td.textContent = cell` 赋值,被字符串化为
   "[object HTMLTableDataCellElement]"——订单方向列颜色从未生效。
   现 `cell instanceof Node ? cell : <新建 td>` 直接挂载元素。
4. 测试: `webui_test.go` TestEnumLocalizationJS(映射/接入点/元素支持
   契约)。
